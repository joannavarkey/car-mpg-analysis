Car MPG Data Analysis Using Python and Excel
This notebook focuses on performing exploratory data analysis and predictive modeling using the Car MPG dataset available in the seaborn bundle. The project was developed as part of the course “Data Analysis Using Python and Excel.”

The notebook includes:
- Data cleaning and preprocessing
- Handling missing values
- Exploratory Data Analysis (EDA)
- Visualization using Matplotlib and Seaborn
- Correlation analysis
- Regression modeling using Scikit-learn
- Model evaluation using MAE and R² score

The objective of the project is to analyze factors affecting vehicle fuel efficiency (MPG) and build a machine learning regression model capable of predicting fuel efficiency based on vehicle characteristics such as horsepower, weight, displacement, and cylinders.

Tools and libraries used:

Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook
